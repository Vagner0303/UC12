O que é html?

A respeito de linguagem de marcação

HTML (HyperText Markup Language) é a linguagem padrão para estruturar e organizar o conteúdo de páginas web, utilizando "tags" (marcações) para definir elementos como títulos, parágrafos, imagens e links.
